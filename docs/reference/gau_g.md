# Five Gaussian Cluster Dataset with Group Labels

A grouped version of
[`gau`](https://yejinjo0220.github.io/dppca/reference/gau.md), with an
additional group label column.

## Usage

``` r
gau_g
```

## Format

A data frame with 1,000 observations and 21 variables. The first 20
columns, named `V1`, `V2`, ..., `V20`, are numerical variables identical
to those in `gau`. The last column, `group`, is a character variable
with values `group1`, `group2`, `group3`, `group4`, and `group5`.

## Source

Generated by the authors of the package.

## Details

The dataset `gau_g` contains the same 1,000 observations and 20
numerical variables as
[`gau`](https://yejinjo0220.github.io/dppca/reference/gau.md), with 200
observations per group. An additional column, `group`, identifies the
five Gaussian clusters. The group labels correspond to the multivariate
normal distributions described in
[`gau`](https://yejinjo0220.github.io/dppca/reference/gau.md).
